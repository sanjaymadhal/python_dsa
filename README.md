## 🧠 How I Study Each Topic

1. **Understand the theory** — Read, watch, take notes
2. **Implement from scratch** — No copy-paste; write it yourself
3. **Trace through examples** — By hand on paper before running
4. **Analyze complexity** — Know the Big-O *before* you test
5. **Solve 3–5 related problems** — From easy to medium
6. **Revisit after a week** — Spaced repetition is the secret

## ⏱️ Complexity Cheat Sheet

| Data Structure | Access | Search | Insert | Delete |
|----------------|--------|--------|--------|--------|
| Array | O(1) | O(n) | O(n) | O(n) |
| Linked List | O(n) | O(n) | O(1) | O(1) |
| Hash Table | — | O(1) avg | O(1) avg | O(1) avg |
| BST (balanced) | O(log n) | O(log n) | O(log n) | O(log n) |
| Heap | O(1) top | — | O(log n) | O(log n) |

| Algorithm | Best | Average | Worst | Space |
|-----------|------|---------|-------|-------|
| Bubble Sort | O(n) | O(n²) | O(n²) | O(1) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) | O(n) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) | O(log n) |
| Binary Search | O(1) | O(log n) | O(log n) | O(1) |
